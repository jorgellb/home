Cap. 09 / FAQ

Resolvemos tus dudas.

Plazos, hosting, propiedad del código, mantenimiento. Si no está aquí, escríbenos y respondemos en menos de 24h.

  1. 01 ¿Cuánto tarda en estar lista mi web? +

    Depende del proyecto. Una landing: 5–7 días. Una web corporativa: 1–2 semanas. Una tienda online: 2–3 semanas. Proyectos a medida según complejidad. Siempre te damos plazo concreto antes de empezar.

  2. 02 ¿Qué es el hosting gratuito para webs estáticas? +

    Las webs sin base de datos (corporativas, portfolios, landings) pueden alojarse gratis en Vercel o Cloudflare Pages. Son más rápidas, más seguras y no pagas hosting mensual. Solo pagas el dominio.

  3. 03 ¿La web es mía o me ato a vosotros? +

    Es 100% tuya. Te entregamos el código fuente, el dominio está a tu nombre y puedes llevarte tu web cuando quieras. Sin permanencia.

  4. 04 ¿Mi web estará optimizada para Google (SEO)? +

    Sí. Todas incluyen SEO técnico: estructura semántica, velocidad optimizada, meta tags, schema markup, sitemap XML, robots.txt y Search Console configurado.

  5. 05 ¿Puedo gestionar el contenido yo mismo? +

    Por supuesto. Panel de administración intuitivo y formación. Si quieres ayuda, planes de mantenimiento desde 39€/mes con horas de cambios incluidas.

  6. 06 ¿Hacéis tiendas con pasarela de pago? +

    Sí. Stripe, PayPal, Redsys (tarjetas españolas), Bizum y transferencia. Todo con SSL y cumpliendo PSD2.

  7. 07 ¿Qué pasa si necesito cambios después? +

    Puedes hacerlos tú desde el panel, contratar un plan de mantenimiento mensual o pedir cambios puntuales bajo presupuesto. Siempre tienes soporte.

  8. 08 ¿Trabajáis solo en Almería? +

    Estamos especializados en empresas de Almería pero trabajamos con clientes de toda España. Lo importante es entender tu negocio, no la distancia.
